## 🚀 Featured Projects

Here are my key open-source projects, demonstrating end-to-end software engineering and machine learning principles:

### 1. [AquaPulse AI 🌊](https://github.com/eswar1310/aquapulse-ai)
**AI-Powered Aquaculture Decision Support System**
* **Core Stack**: Next.js 15 (TypeScript), FastAPI (Python), OpenRouter LLMs/Vision, Supabase, OpenWeather API.
* **Impact**: Mitigates aquaculture production risk by providing farmers with image-based disease scanning, automatic PDF pond report analysis, live market sentiment indicators, and automated news feeds.
* *Deployment*: Deployed live on Vercel and Render.

### 2. [Microservices RAG Chatbot & Summarizer 📦](https://github.com/eswar1310/microservices-rag-chatbot)
**Docker-Orchestrated Multi-Container NLP System**
* **Core Stack**: FastAPI, LangChain, ChromaDB, Hugging Face Hub (Embeddings & LLMs), Docker Compose, MySQL.
* **Impact**: Implements a complete microservice architecture featuring three separate services: a User Authentication service (OAuth2/JWT), a RAG-based PDF/URL Chatbot service, and a Seq2Seq summarization service.
* *Deployment*: Fully containerized and orchestrable with a single `docker-compose up` command.

### 3. [Vinu Music Studio 🎶](https://github.com/eswar1310/AI-Studio)
**Local-First AI Music Production DAW**
* **Core Stack**: React, Vite, FastAPI, Meta MusicGen, AudioLDM, Demucs v4 (Audio Separation), FFmpeg.
* **Impact**: Runs state-of-the-art music and sound effect generation locally. Features an interactive multitrack timeline (trim, split, volume, pan) synchronized with video playback for sound scoring.
* *Local Focus*: High-performance local caching and model management to minimize API dependency.

### 4. [Predictive ML Portfolio 📊](https://github.com/eswar1310/predictive-ml-portfolio)
**Curated Machine Learning Models for Risk & Classification**
* **Core Stack**: Scikit-Learn, LightGBM, Pandas, Seaborn, Jupyter Notebooks.
* **Key Studies**: 
  - *French Motor Insurance Claims*: Claim classification using the Kaggle freMTPL2 dataset.
  - *Credit Card Approval*: Application scoring utilizing Gradient Boosting and Random Forests.
  - *Amazon Sales Classification*: Predictive modeling to identify orders at risk of rejection.
